# ☀️ Traspadini UV - Projeto de E-Commerce & Catálogo de Moda UV

[![Acessar o Site](https://img.shields.io/badge/🚀_Acessar_o_Site-Clique_Aqui-orange?style=for-the-badge)](https://thatalisson.github.io/traspadini_uv_site/loja.html)

Esse é o projeto piloto de um site moderno e responsivo para a loja em que trabalho: a **Traspadini UV**, especializada em vestuário de alta performance, proteção UV, uniformes personalizados e acessórios de alta durabilidade.

---

## 📸 Demonstração do Projeto

O projeto conta com um design escuro (*Dark Theme*) e detalhes translúcidos (estilo *Glassmorphism*).

---

## 🚀 Funcionalidades

- **Design Responsivo & Estático** para garantir leitura limpa.
- **Catálogo de Produtos**: Exibição dos produtos com imagens individuais e descrições personalizadas.
- **Seção Hero / Banner**: Chamada principal destacando peças de alta performance.
- **Uniformes Personalizados**: Espaço para solicitação de peças sob medida.
- **Carrinho de Compras**: Componente interativo para controle de itens selecionados.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica das páginas.
- **CSS3**: Estilização moderna com variáveis `:root`, flexbox, grid e suporte a *Glassmorphism*.
- **JavaScript (Vanilla)**: Interatividade da loja e carrinho de compras.

## 💻 Como Rodar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU-USUARIO/traspadini-uv.git
   ```

2. **Navegue até o diretório:**
   ```bash
   cd traspadini-uv
   ```

3. **Execute o projeto:**
   - Abra o arquivo `index.html` diretamente em seu navegador, ou
   - Utilise a extensão **Live Server** no VS Code para uma melhor experiência de desenvolvimento.
